# Glossário

| Termo | O que quer dizer aqui |
|---|---|
| **Souls-like** | Combate de reacção com esquiva, parry e stamina, dificuldade que se vence com perícia. Referência: Dark Souls. |
| **Pilar 1** | "Ganha-se com habilidade, não com nível." A regra que não se negoceia. |
| **Gating** | Trancar conteúdo atrás de um nível mínimo. Proibido por decisão (sessão 1 · 01:17). |
| **Soft gating** | Deixar ir a qualquer lado, mas as zonas difíceis castigam já. Candidato a resolver a tensão dos biomas. Não decidido. |
| **Parry** | Aparar o golpe no momento exacto, abrindo o inimigo. |
| **Drop** | Item largado por um inimigo. Como funciona em co-op está em aberto. |
| **Sessão N** | Gravação de conversa. Referências na spec são `(sessão N · MM:SS)`. |
| **Fable** | O agente do Rico, que vai construir a partir desta spec. |
