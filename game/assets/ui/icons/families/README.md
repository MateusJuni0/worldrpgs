# Ícones das famílias de armas

Oito SVG transparentes desenhados para continuarem distintos a **32×32 px**.
A silhueta resolve a família; cor e brilho são apenas o segundo nível de leitura.

`WeaponFamilyIcons.texture_for(family_id)` liga directamente os IDs de
`weapons.json` a estes assets. Escudos são uma taxonomia separada e não fazem
parte das oito famílias.
