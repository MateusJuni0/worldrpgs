# design/

Matéria-prima das sessões.

| Pasta | O que tem |
|---|---|
| `transcripts/` | Transcrição verbatim de cada sessão, com timestamps |
| `ideas/` | As ideias de cada sessão, organizadas |

**As transcrições estão fora deste repositório, por agora.** São o registo verbatim de uma conversa privada entre o Mateus e o Rico, e isto é público — uma vez no histórico do git, não sai. Ficam locais até haver decisão dos dois.

As gravações em si (centenas de MB) nunca entram, em caso nenhum — ver `.gitignore`.

O conteúdo que interessa está na `spec/`, e cada afirmação cita o timestamp de onde saiu.

Tudo o que está na `spec/` sai daqui, e cita o timestamp de origem.
